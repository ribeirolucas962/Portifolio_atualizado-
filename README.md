<summary><strong>Sobre este repositório</strong></summary>

<br>

Site em HTML, CSS e JavaScript puros — sem framework, sem build, sem dependências para instalar.

```
index.html         Página principal
trajetoria.html    Trajetória profissional (estilos próprios embutidos)
styles.css         Estilos da página principal
script.js          Interatividade + catálogo de certificados (certificatesData)
certificados/      PDFs organizados por categoria
imagens/           Fotos, thumbnails e logos
projetos/          Arquivos de projeto
```

**Rodar localmente** — abra o `index.html` no navegador, ou sirva por HTTP para que os PDFs carreguem sem restrições:

```bash
python -m http.server 8000   # http://localhost:8000
```

**Adicionar um certificado** — coloque o PDF em `certificados/{Categoria}/` e adicione a entrada em `certificatesData.categories` no `script.js`:

```js
{
    "courseName": "Nome do curso",
    "institution": "Instituição",
    "filePath": "certificados/Categoria/arquivo.pdf"
}
```

O card e o modal são gerados automaticamente. Use nomes de arquivo sem colchetes — caminhos como `Projeto [v2].pdf` quebram quando servidos por HTTP.

Detalhes de arquitetura em [`.github/copilot-instructions.md`](./.github/copilot-instructions.md).

**Dependências via CDN:** Font Awesome 6 (ícones) e Google Fonts / Poppins (tipografia).

</details>
